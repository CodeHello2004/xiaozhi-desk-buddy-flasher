Checking this computer’s current UTC offset…
Use desktop Google Chrome or Microsoft Edge, which support Web Serial. The installer must be opened from a secure HTTPS website.
  1. Connect the XIAO with a USB data cable.
  2. Choose your country or current UTC offset.
  3. Click the install button and choose the XIAO serial port.
  4. After reboot, connect to the Xiaozhi setup hotspot and enter your Wi-Fi details.
  5. Wait for the six-digit activation code on the OLED.
  6. Open xiaozhi.me, add a device, and enter that code to bind your agent.
The selected offset is fixed. If your country changes clocks for daylight saving time, choose its current UTC offset when flashing. Installation clears saved Wi-Fi settings. If this physical board is already listed in xiaozhi.me, delete that old device entry before installing so the server will issue a new activation code.
